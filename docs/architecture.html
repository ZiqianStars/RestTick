RestTick · Architecture

项目架构

菜单栏常驻的休息提醒工具：以“累计清醒使用时间”为计时依据，到点弹出全屏护眼遮罩。 代码按入口、调度、呈现、系统与资源四层划分，共 10 个 Swift 文件、约 1750 行，无第三方依赖。

macOS 13+ SwiftUI + AppKit SwiftPM 10 个模块 0 个第三方依赖

分层与依赖

箭头表示“持有/调用”方向；虚线表示弱引用回调。基础层只被上层调用，不反向依赖界面。

入口层 调度层 呈现层 系统与资源层 实线 = 持有/调用　虚线 = 弱引用回调

模块职责

应用代码位于 Sources/RestTick，计时规则拆到 Sources/RestTickCore，测试在 Tests/RestTickTests。

模块文件职责主要依赖
应用入口 RestTickApp.swift 声明 MenuBarExtra 场景；AppDelegate 注册 resttick:// URL 与 --break-now 启动参数；设置 accessory 激活策略。 RestTickEngine、MenuBarView
计时规则 RestTickCore/RestTickRules.swift 纯函数规则：空闲判定、累计封顶、倒计时格式、进度比例、次日零点计算；独立成库以便单元测试与复用。 Foundation
计时调度 RestTickEngine.swift 计时状态机（计时/休息/暂停）；累计清醒使用时长；分频定时器；系统唤醒、锁屏、屏保事件；预告与遮罩的编排。 OverlayController、PrewarnToast、WallpaperStore、SystemServices
遮罩控制 OverlayController.swift 为每块屏幕创建非激活 NSPanel；淡入淡出；监听屏幕参数变化重建；OverlayRotationModel 负责 18 秒轮换与跨屏同步、预解码下一张。 BreakOverlayView、WallpaperStore、RestTickEngine（弱引用）
遮罩界面 BreakOverlayView.swift 背景图（scaledToFill）+ 压暗蒙版；倒计时与提示语；长按 3 秒跳过；暂停/今天不再提醒入口。 RestTickEngine、OverlayRotationModel
预告浮层 PrewarnToast.swift 剩余 45 秒时在右上角显示非侵入浮层，忽略鼠标事件，9 秒自动消失。 AppKit
菜单栏界面 MenuBarView.swift 倒计时、进度、状态徽标；专注/休息时长设置；现在休息、暂停、继续、重新计时、打开图库、退出；底部说明。 RestTickEngine、LoginItemManager、WallpaperStore
图库与图片 WallpaperStore.swift 扫描图库目录；首次运行把内置照片复制到 Application Support；后台 ImageIO 降采样解码；NSCache 缓存与清单签名失效。 CoreGraphics、ImageIO、AppKit
系统能力 SystemServices.swift 单调时钟（含/不含休眠）；键鼠空闲秒数；锁屏状态；检测其他进程的防显示器休眠断言。 IOKit.pwr_mgt、CoreGraphics
登录项 LoginItem.swift 通过 SMAppService 注册/注销开机自启；读取系统真实状态；需批准时打开系统设置。 ServiceManagement

关键运行路径

四条主链路串起计时、休息、暂停与启动。

计时与触发

每秒 tick → 检查空闲 / 锁屏 / 屏保 / 媒体断言 → 累计清醒时长（单次增量封顶 5 秒）→ 剩余 45 秒发预告 → 归零调用 beginBreak()。

休息与轮换

overlay.show() 先弹遮罩 → 后台 WallpaperStore.reload() → 每次扫描完成后更新数量 → 每 18 秒换图并预解码下一张 → 到点或长按 3 秒结束。

暂停与恢复

暂停阶段改用一次性 Timer，只在恢复时刻唤醒；恢复时重置时钟基准。休息中暂停会清零累计，恢复后重新走完整周期，避免立刻再弹遮罩。

启动预热

启动注册系统通知与计时器；3 秒后 prewarm() 在后台扫描图库并解码首图，首次休息无需等待。
