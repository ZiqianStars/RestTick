# RestTick 需求列表

- 版本：1.0（基于当前实现整理）
- 日期：2026-11-25
- 平台：macOS 13+
- 状态说明：**已实现** / **部分实现** / **未实现**

## 一、功能需求

| 编号 | 需求 | 验收要点 | 状态 |
| --- | --- | --- | --- |
| F-01 | 专注计时 | 默认 45 分钟，可在菜单栏调整 5–180 分钟（步长 5）；修改后立即生效并持久化 | 已实现 |
| F-02 | 休息时长 | 默认 5 分钟，可调 1–30 分钟；到点自动结束休息 | 已实现 |
| F-03 | 只统计清醒活跃时间 | 键鼠空闲 ≥ 90 秒、锁屏、屏保时暂停累计；回到电脑前自动继续 | 已实现 |
| F-04 | 媒体播放豁免 | 其他进程持有“防显示器休眠”断言（看视频、caffeinate）时，空闲也继续计时 | 已实现 |
| F-05 | 睡眠/唤醒校准 | 系统休眠时间不计入使用时长；唤醒后按单调时钟校准，休息/暂停到点自动收尾 | 已实现 |
| F-06 | 到期预告 | 剩余 45 秒时右上角浮层提醒，不抢焦点、不拦截鼠标、9 秒自动消失；锁屏/屏保时不弹 | 已实现 |
| F-07 | 全屏休息遮罩 | 每块显示器一个窗口；0.7 s 淡入、0.6 s 淡出；非激活面板，不锁屏、不阻止系统休眠 | 已实现 |
| F-08 | 遮罩内容与操作 | 显示倒计时与提示语；长按 3 秒跳过；可暂停 30 分钟或今天不再提醒 | 已实现 |
| F-09 | 遮罩首次点击即生效 | 后台弹出时第一次点击直接落到按钮/长按手势，无需点两次 | 已实现 |
| F-10 | 背景图轮换 | 内置 5 张护眼照片；每 18 秒切换，多屏同步；每次休息从上一张的下一张开始；提前解码下一张；复制到运行时目录后按内容哈希比对，内置图更新会自动覆盖同名旧图 | 已实现 |
| F-11 | 自定义图库 | `Application Support/RestTick/Backgrounds` 支持 png/jpg/jpeg/heic/tif/tiff；有自定义图时优先使用；每次开始休息重新扫描 | 已实现 |
| F-12 | 打开图库入口 | 菜单栏一键打开背景图文件夹，放入图片即可使用 | 已实现 |
| F-13 | 菜单栏常驻与状态 | 图标随计时/空闲/暂停/休息变化；展示剩余时间、进度和状态文案 | 已实现 |
| F-14 | 菜单操作 | 现在休息、暂停 30 分钟、今天不再提醒、继续计时、重新计时、退出 | 已实现 |
| F-15 | 暂停与恢复 | 暂停到期自动恢复；休息中暂停后恢复会重新开始完整周期，不会立刻再弹遮罩（含跨零点） | 已实现 |
| F-16 | 开机自启 | 通过 `SMAppService` 注册/注销；需系统批准时引导到“登录项”设置；状态以系统为准 | 已实现 |
| F-17 | 外部触发休息 | 支持 `resttick://break` 与启动参数 `--break-now`（自动化/调试用） | 已实现 |
| F-18 | 完成/跳过统计 | 菜单底部展示本次运行内完成、跳过的休息次数 | 部分实现（仅内存，重启清零） |
| F-19 | 休息结束提醒 | 结束后在菜单栏显示文案；无系统通知与提示音 | 未实现 |
| F-20 | 免打扰场景识别 | 不检测全屏演示、视频会议、系统勿扰模式；仅通过媒体断言豁免 | 未实现 |
| F-21 | 单张背景管理 | 无收藏、单张删除、内置图替换 UI（可手动改文件夹） | 未实现 |
| F-22 | 多语言 | 界面仅简体中文 | 未实现 |
| F-23 | 使用统计与趋势 | 无按天/周统计、无图表、无持久化历史 | 未实现 |

## 二、非功能需求

| 编号 | 类别 | 需求 | 状态 |
| --- | --- | --- | --- |
| N-01 | 平台与依赖 | macOS 13+；SwiftUI + AppKit；SwiftPM 构建；无第三方依赖 | 已实现 |
| N-02 | 常驻方式 | `LSUIElement` 菜单栏应用，不显示 Dock 图标 | 已实现 |
| N-03 | 计时精度 | 使用 `mach_absolute_time` / `mach_continuous_time`；单次 tick 增量截断 5 秒，避免系统合并计时器造成跳变 | 已实现 |
| N-04 | 能效 | 计时/休息 1 秒 tick；暂停阶段只在恢复时刻唤醒；锁屏 2 秒、媒体断言 5 秒降频检查 | 已实现 |
| N-05 | 响应性 | 图库扫描与图片解码在后台队列；遮罩先弹出，扫描完成后再更新轮换清单 | 已实现 |
| N-06 | 内存控制 | 图片按最大屏幕像素长边降采样（1600–4096）；`NSCache` 上限 3 张 / 96 MB | 已实现 |
| N-07 | 缓存正确性 | 清单签名（文件名+大小+修改时间+目标像素）不变时不清空缓存 | 已实现 |
| N-08 | 内置资源体积 | 5 张 2048×1280 JPEG，合计约 2.4 MB | 已实现 |
| N-09 | 离线可用 | 背景图随 App 打包，运行期无网络请求 | 已实现 |
| N-10 | 授权合规 | 图片来自 Pexels，遵循 Pexels License：可免费商用、可修改、无需署名；不可转售未修改原图、不可暗示 Pexels/摄影师背书；仓库仅保留 5 张内置图，授权说明见 README | 已实现 |
| N-11 | 隐私 | 仅在本地读取键鼠空闲、锁屏/屏保状态与电源断言，不上传任何数据 | 已实现 |
| N-12 | 稳定性 | Ad-hoc 签名；release 构建通过；实测休息遮罩与图片轮换无崩溃 | 已实现 |
| N-13 | 多显示器/分辨率 | 每屏独立窗口；`scaledToFill` 裁切；屏幕参数变化时重建窗口 | 已实现 |
| N-14 | 可访问性 | 图标按钮带 `accessibilityLabel`；遮罩文字依赖图片压暗蒙版保证对比度，未做专项测试 | 部分实现 |
| N-15 | 可测试性 | 新增 `Tests/RestTickTests` 测试 target 与 `scripts/test.sh`，覆盖空闲判定、累计封顶、倒计时与归零、进度、跨天/夏令时恢复、内置图规格（36 项检查）；当前工具链为 CommandLineTools，不含 XCTest 且 Swift Testing 宏插件不可用，故采用独立断言运行器 | 已实现 |
| N-16 | 性能指标 | 未定义首帧时间、CPU/内存占用等量化目标与基线 | 未实现 |
| N-17 | 可维护性 | 按职责拆分模块，关键设计（计时校准、缓存、轮换）有注释说明 | 已实现 |
| N-18 | 分发 | `scripts/package.sh` 生成可拖拽安装的 DMG（已验证挂载与签名）；本机无 Developer ID 证书，当前为 ad-hoc 签名，脚本支持配置证书与 `notarytool` 公证，但未实际执行 | 部分实现 |
| N-19 | 日志与诊断 | 接入 OSLog 统一日志（subsystem `com.resttick.app`，分 app/engine/overlay/wallpaper/login 五个 category），记录启动、计时状态变化、图库变更、解码/复制失败、遮罩显隐与登录项错误；可用 `/usr/bin/log show --predicate 'subsystem == "com.resttick.app"'` 查看 | 已实现 |
| N-20 | 时区/夏令时 | “今天不再提醒”用 `Calendar` 计算次日零点，兼容夏令时切换 | 已实现 |

## 三、本轮变更

- 内置背景由 5 张程序生成渐变图改为 5 张真实照片（候选 A/D/E/F/G）。
- 原图按遮罩常用比例 16:10 居中裁切为 2048×1280，JPEG 压缩后合计约 2.4 MB。
- 图片打包进 `RestTick.app/Contents/Resources/Backgrounds`，首次运行复制到图库目录，并清理旧渐变 PNG。
- 移除了 `WallpaperStore` 中的渐变绘制代码。
- 5 张内置图均来自 Pexels，遵循 Pexels License；原始文件见 `Resources/Backgrounds/`。

## 四、本轮变更（N-15 / N-19 / N-18）

- **N-15**：新增 `RestTickCore` 库（纯函数计时规则）与 `Tests/RestTickTests` 测试 target；`scripts/test.sh` 运行 36 项断言。
- **N-19**：新增 OSLog 统一日志，覆盖状态切换、图库、遮罩、登录项与错误路径。
- **N-18**：新增 `scripts/package.sh`，生成 `dist/RestTick-1.0.0.dmg`；已验证挂载、应用包结构与签名，公证需外部证书与账号。

## 五、本轮变更（倒计时归零修复）

- 修复休息倒计时卡在 `00:01`、遮罩不撤的问题：显示值刷新有 0.01 秒阈值，剩余 0.005 秒时目标归零被忽略，结束条件 `remaining <= 0` 永远不成立。
- 新增 `RestTickRules.refreshedRemaining`，目标归零时立即归零；回归测试补充到 36 项。
- 实测 1 分钟休息 + 1 分钟专注：休息在 60 秒后正常结束并淡出，下一轮休息能自动开始。
